What it is

multi-run (the command is mr) takes a handful of commands, starts each one in its own tmux session, and shows every job as a tile in one terminal UI. Press Enter or double-click to expand a job to full screen, then Enter or a to attach for real interactive access. Ctrl-\ jumps back out.

Sessions keep running after you quit, so you can close the UI and come back later with mr -a g1. Each mr invocation is a group, and its jobs are numbered g1.1, g1.2, and so on.

┌ g1.1 ✓ cargo fmt --check ─────────────────────── exit 0 ┐
│                                                         │
└─────────────────────────────────────────────────────────┘
┌ g1.2 ● cargo watch -x test ───────────────── 4s running ┐
│running 12 tests                                         │
│test model::advance ... ok                               │
└─────────────────────────────────────────────────────────┘
grid  g1.1 cargo fmt --check    ?:help  v:view  n:new  q:quit

Features

  • Parallel jobs, one screen: every command gets a tile with a live status (running, exit 0, and so on)
  • Real attach: drop into any job's actual shell in tmux, and Ctrl-\ back to the grid
  • Persistent sessions: jobs keep running after you quit; mr --list shows groups and mr -a reopens one
  • Adaptive layout: full-width rows, columns, or a grid depending on terminal size, plus a list view you can switch to with v
  • Job control: stop with escalating signals, send EOF, re-run a command, or dismiss finished jobs
  • Compose screen: run mr with no arguments to queue up commands interactively
  • Keyboard and mouse: vim-style navigation, click to focus, double-click to expand, wheel to scroll output
  • Plays nice with your tmux: runs on a private tmux server that still sources your ~/.tmux.conf
  • Self-updating: mr --update checks GitHub and replaces the binary if a newer release exists

Getting started

Install the latest release (macOS Apple Silicon/Intel, Linux x86_64/ARM64). You also need tmux 3.3 or newer on your PATH. Then, from a project directory, pass each job as a quoted string:

curl -fsSL https://raw.githubusercontent.com/faulker/multi-run/main/install.sh | bash

mr "cargo watch -x test" "npm run dev"
